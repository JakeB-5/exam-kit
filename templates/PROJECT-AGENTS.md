# 최소 프로젝트 컨텍스트 작성 기준

설치자가 과제 자료를 읽고 아래 두 가지만 과제 루트 AGENTS.md에 작성한다. 이 설명이나 빈 틀을 그대로 복사하지 않는다.

1. **프로젝트 소개**: 누가 무엇을 위해 사용하는 프로젝트인지 한 짧은 문단.
2. **주의사항**: 작업이 바뀌어도 유효한 프로젝트 고유의 중요한 사항 몇 개. 예: 자료 밖의 정책을 지어내지 않기, 기존 데이터/상태 보존, 민감정보 경계. 실제 과제에 해당하는 내용만 쓴다.

그 밖의 항목을 기본 생성하지 않는다. 초기 기획 순서, 문서 필독 목록, 현재 단계/다음 작업, 상세 요구사항, 도구 사용법, 실행·검증·보고 절차는 해당 문서에 둔다. 그 문서들을 모든 세션에서 읽거나 자동 import하도록 지시하지 않는다.

소개와 주의사항이 정확하면 충분하다. 줄 수나 섹션 수를 채우지 않는다. 기존 사용자의 지침은 별도 수정 요청 없이 삭제하지 않는다.
